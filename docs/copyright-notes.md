# Copyright Notes

This project is being structured to avoid unnecessary reproduction of official rulebook text.

## Safer Practices

- Use original summaries written for this app.
- Avoid copying complete rule entries, ability text, class text, or book tables.
- Use placeholders where official mechanics would otherwise be copied.
- Consider page references for private use.
- Keep the repository private while developing against official source material.

## Public Release Checklist

Before publishing publicly:

- Review the publisher's fan-content or community-use policy.
- Remove copied excerpts, if any were added during private development.
- Confirm whether names, terminology, and presentation are allowed.
- Add attribution and disclaimers where required.
- Consider making the app a companion tool that requires book ownership.
