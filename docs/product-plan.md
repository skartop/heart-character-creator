# Product Plan

## Product Vision

Create a guided web app that helps players build *Heart: The City Beneath* characters through contextual choices, recommendations, deferred questions, and exportable summaries.

## Target Users

- New players who need help understanding what each choice implies
- Returning players who want faster character creation
- GMs who want party hooks, drives, and unresolved questions visible before session one

## MVP Scope

1. Character concept capture
2. Ancestry selection
3. Calling selection
4. Class concept selection
5. Character questions
6. Deferred question tracking
7. Local browser save
8. Markdown export

## Future Scope

- Full party/session workspace
- GM dashboard
- Beats tracker
- Fallout tracker
- PDF export
- Shareable read-only character links
- AI-assisted recommendation mode
- Custom table content packs

## Copyright-Safe Content Strategy

- Store original summaries, not copied rulebook text
- Use placeholders where rules text would be needed
- Allow private table data entry
- Add page-reference fields later if useful
- Review publisher policy before any public release
