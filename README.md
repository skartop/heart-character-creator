# Heart Character Creator

An unofficial, static character-building companion for the core game of *Heart: The City Beneath*.

## Run locally

```sh
npm install
npm run dev
```

Run checks with `npm test` and create a production build with `npm run build`.

## Deployment

The GitHub Actions workflow deploys the `main` branch to GitHub Pages. After pushing this project to GitHub, enable **Settings → Pages → GitHub Actions** in the repository.

## Content and template notice

This project deliberately provides original, short-form character prompts rather than reproducing full rules text, tables, or sourcebook art. Users need the official game for exact mechanical details.

`public/heart-character-sheet.pdf` is the official sheet template supplied by the project owner and is overlaid locally in the browser for export. Remove or replace it promptly if the rights holder requests it.
